# 波斯灣航運全景動態海圖與上市股票觀測站 (Persian Gulf Shipping Terminal)

> **遵循 IMO ECDIS S-52 數位海圖標準** 打造的波斯灣（阿拉伯灣）海運與地緣戰情觀測站。完整繪製全球通往中東波斯灣的航運路線、荷姆茲海峽分道通航制（TSS）、12 大樞紐港口，並整合國內外上市航運股票即時行情與籌碼戰情分析。

---

## 🗺️ 核心特色與功能模組

### 1. 依照 ECDIS 數位海圖規範繪製之互動海圖
* **夜間數位海圖標準 (Night Mode S-52)**：深海黑藍水深階梯（<10m 淺棚、20-80m 中央深槽、>100m 阿曼灣深水洋盆）。
* **WGS-84 經緯度網格**：精準標註 24°N~30°N、48°E~60°E。
* **360° 航海羅經盤 (Compass Rose)** 與 **TSS 航制標記**。
* **五大動態光流航線**：
  * 🟢 **遠東直達幹線 (Asia Direct)**：上海/寧波/高雄/新加坡 → 荷姆茲進港道 → Jebel Ali / Dammam
  * 🟠 **歐洲/地中海幹線 (Europe/Med)**：好望角繞道 → 阿曼灣 → 荷姆茲進港道 → Jebel Ali / Hamad
  * 🟡 **VLCC 原油與 LNG 出口動脈 (Crude & Gas Export)**：拉斯塔努拉/巴士拉/拉斯拉凡 → 中央深槽 → 荷姆茲出港道 → 遠東/歐美
  * 🔵 **灣內支線駁運 (Regional Feeders)**：以杜拜 Jebel Ali 為母港輻射至科威特、伊拉克、巴林、卡達
  * 🟣 **阿聯酋富吉拉陸上繞道油管 (ADCOP Pipeline)**：哈布善油田直通外海富吉拉港，完全避開海峽軍事風險
* **航商專屬航線高亮濾鏡**：點選長榮、萬海、陽明、MSC、Maersk、Bahri、Frontline、DHT 等，地圖自動聚焦其專屬航線與掛靠港口。

### 2. 12 大樞紐港口全景檔案 (12 Hub Ports Dossier)
* **Jebel Ali（阿聯酋杜拜）**：全球第十大貨櫃港、中東不可撼動心臟、海空聯運中繼站。
* **Khalifa Port（阿聯酋阿布達比）**：中遠海運 CSP 專屬自營半自動化深水碼頭。
* **King Abdulaziz Port, Dammam（沙烏地達曼）**：沙國東部商港、利雅德鐵路起點。
* **Jubail Port（沙烏地朱拜勒）**：全球最大單一石化聚落重載專用港。
* **Hamad Port（卡達哈馬德）**：卡達超級現代化國家深水主港。
* **Ras Laffan（卡達拉斯拉凡）**：全球最大 LNG 液化天然氣出口終端港（Nakilat 基地）。
* **Khalifa Bin Salman Port（巴林）**：法赫德國王跨海大橋直通沙烏地之自由保稅轉運島。
* **Shuwaikh Port（科威特舒威赫）**：首都民生物資核心進口商港。
* **Umm Qasr Port（伊拉克烏姆蓋斯爾）**：伊拉克唯一出海深水商港、戰後重建生命線。
* **Bandar Abbas（伊朗阿巴斯）**：荷姆茲海峽北側軍政戰略大港、南北運輸走廊 (INSTC) 樞紐。
* **Port of Fujairah（阿聯酋富吉拉）**：荷姆茲海峽外阿曼灣、全球第二大加油港兼 ADCOP 油管終端。
* **Port of Sohar（阿曼蘇哈爾）**：海峽外緣戰略避險深水港、自由貿易區。

### 4. 波斯灣航運三大地緣戰略關鍵深度分析
1. **荷姆茲海峽 TSS 航制咽喉**：最窄僅 21 海浬，滿載 VLCC 只能走深水槽，地緣衝突推升戰險保費 (AWRP)。
2. **紅海危機外溢推升 Jebel Ali 海空聯運**：亞洲海運至杜拜 Jebel Ali，在自貿區快速拆箱直通杜拜世界中心機場 (DWC) 空運歐洲，節省 12-15 天。
3. **繞行海峽之陸上戰略輸油管**：阿聯酋 ADCOP 油管（150萬桶/日）與沙烏地 Petroline 油管（500萬桶/日）戰略破局。
